## What I do
- Write single-capability requirements using RFC 2119 normative vocabulary (SHALL, SHALL NOT, SHOULD, MAY)
- Produce Doorstop-compatible YAML requirement files
- Distinguish deterministic requirements from probabilistic ones with evaluation protocols
- Define guardrails, observability, and human-in-the-loop escalation conditions for AI agents

## When to use me
Use this skill when creating new requirements, refining existing ones, or converting user stories into formal specifications.
Always verify the requirement is specific, measurable, and traceable to a parent need.
